# 🏔️ Parallax Effect

A visually immersive, multi-layered parallax scrolling web experience showcasing outdoor adventure sports built with pure HTML5 and CSS3.

Check out the live deployment here: **[https://adventureparallaxeffect.netlify.app/](https://adventureparallaxeffect.netlify.app/)**

## ✨ Features

- **3D Perspective Parallax Header**: Multi-layered depth illusion using CSS 3D transforms (`perspective`, `transform-style: preserve-3d`, `translateZ`).
- **Fixed Background Scrolling**: Smooth visual depth transitions across adventure sections (Biking, Paragliding, Surfing).
- **Zero JS Overhead**: Pure HTML5 and CSS3 implementation for ultra-fast performance.
- **Clean & Minimal Design**: Focused on aesthetics and interactive visual depth.

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (3D Transforms & Fixed Background Attachments)
